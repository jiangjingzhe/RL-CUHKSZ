本章怎样学

本章围绕一个问题展开：怎样让一个决策者从自己的尝试及其结果中学会更好的行为？

学完后，你应能用一个具体任务说明智能体、环境、状态、动作、奖励和策略，算出简单的折扣回报，分清奖励与价值，并手算一次井字棋价值更新。LLM 算法部分是课程预告，本周先理解各个组件的作用。

1. 强化学习要解决什么问题

来源：P3、P20–26。

1.1 定义里的每个词都重要

强化学习（Reinforcement Learning，RL）：智能体通过经验学习如何行动，目标是最大化期望累积奖励。

关键词 含义
智能体 Agent 作出决策的部分，不一定是整个机器人
经验 Experience 做过什么、进入什么情境、得到什么反馈
学习行动 经验会改变以后的决策规则
奖励 Reward 用数值评价结果，不一定告诉智能体正确动作
累积 Cumulative 关心一段时间的总收益，当前有代价的动作可能以后有益
期望 Expected 在随机环境或随机策略下，关注平均意义上的表现

动作既影响以后获得奖励的机会，也影响之后收集到的经验。这让“学习什么”和“接下来做什么”互相影响。

“RL”也有三个使用层次：它可以指决策问题，指从经验学习策略、价值或模型的方法，也可以指研究这些问题、算法及其性质的领域。不要因为某个算法没有在线试错，就仅凭这一点把它排除在整个 RL 理论框架之外。

1.2 原例：机器人导航中的学习与规划

做法 输入与工作方式
从经验学习 机器人尝试移动，根据奖励学会到达目标
规划 Planning 给定地图和运动规则，计算到达目标的路线
基于模型的 RL 先从经验学习运动模型，再用模型规划路线

动态规划（Dynamic Programming，DP）利用已知的状态转移和奖励模型计算价值与策略。它不必通过真实交互学习模型，但其价值函数和策略改进思想是很多 RL 算法的基础。

1.3 从完整智能体的角度理解任务

智能体感知情境、采取动作，并通过反馈评价目标完成情况。感知、预测和规划都服务于这个交互过程。

原例：电池管理智能体。 它读取电量并请求充电；机器人其余部分都可以算入环境。所谓“完整智能体”，强调感知、行动、目标组成的闭环，不要求智能体包含整台物理机器。

1.4 与其他学习设置的关系

设置 典型学习信号
监督学习 正确标签或示范
无监督学习 数据中可发现的结构
强化学习 与动作及其后果关联的奖励

RL 内部可以使用监督学习，例如拟合价值函数或环境模型。在线 RL 在学习过程中收集新交互；离线 RL 从已有数据集学习策略，困难之一是未出现过的动作缺乏可靠证据。训练也可以在模拟环境中进行，因此 RL 并不要求训练期间在真实系统上试验。

1.5 原例：探索与利用

动作 已观察奖励的均值 尝试次数
A 0.6 100
B 0.5 2

利用（Exploitation）：按当前估计，选择较好的 A 获取奖励。探索（Exploration）：尝试 B，获得可能改善未来决策的信息。

只剩一次决策时，按样本均值选择 A 更有理由；如果还要决策很多次，了解 B 可能值得。表格不足以唯一确定最优选择：还需要考虑奖励的不确定性、先验信息和剩余轮数。B 的均值低，不代表它的真实表现一定差；只观察两次，结论还不稳固。

补充解释：探索的价值从哪里来？ 这次试 B 可能少赚，但若发现 B 实际更好，后面很多次选择都能受益。为了未来的学习收益，当前可以接受一定的奖励损失。

1.6 课件列举的任务

智能体 决策 长期目标
游戏玩家 下一步走哪里 赢下整局
移动机器人 移动还是充电 在能量和故障约束下完成任务
工厂控制器 使用哪些运行参数 高效生产有用的产品
语言模型 下一个 token 或工具动作 生成成功的回答或完成任务

这些任务都可能存在多步依赖和延迟反馈。

原例：送货机器人（P25）。 简化任务只在交付时奖励 +1，其他时候奖励 0。

当前情境 动作 下一情境 奖励
岔路口 转入走廊 办公室附近 0
办公室附近 靠近门口 办公室门口 0
办公室门口 交付包裹 任务完成 +1

岔路口选择不同方向，会改变后续位置与可选动作，这是顺序依赖。奖励最后才出现，但之前转弯也有贡献，这是延迟奖励与信用分配问题。

原例：回收机器人（P26）。 这个模型只保留电量，暂时抽象掉位置和导航。

  • 智能体：决策控制器；环境：机器人身体和周围世界。
  • 状态：高电量或低电量。
  • 动作：搜索空罐（平均收获多，但耗电）、等待别人送罐（收获较少，但省电）、充电（只在低电量时可选）。
  • 奖励：每收集一个罐子 +1；电量耗尽、需要救援时 −3；其他情况为 0。
  • 策略：根据电量选择动作的规则。

充电当下奖励为 0，却能支持后续继续收集空罐。目标是累积收益，而不是每一步都得到最多罐子。

2. 为什么语言模型也用强化学习

来源：P4–11。本节是算法预览，详细推导留待后续周。

2.1 预训练、SFT 和 RL 的目标

预训练学习预测大规模文本中的 token；监督微调（SFT）模仿选好的示范；RL 后训练则评价模型自己生成的回答，根据反馈调整行为。

设提示为 xxx，回答为 yyy，策略参数为 θ\thetaθ，数据分布为 DDD。

SFT:max⁡θ  E(x,y)∼D[log⁡πθ(y∣x)].\text{SFT}:\quad \max_\theta\;\mathbb E_{(x,y)\sim D}[\log\pi_\theta(y\mid x)].SFT:θmax​E(x,y)∼D​[logπθ​(y∣x)].
RL:max⁡θ  Ex∼D,  y∼πθ(⋅∣x)[r(x,y)].\text{RL}:\quad \max_\theta\;\mathbb E_{x\sim D,\;y\sim\pi_\theta(\cdot\mid x)}[r(x,y)].RL:θmax​Ex∼D,y∼πθ​(⋅∣x)​[r(x,y)].

SFT 增大数据集里示范回答的概率；RL 增大自己采样到的高奖励回答所对应行为的倾向。有些任务的答案容易验证，却难以逐条给出优质示范。预训练模型提供了有用的初始策略，RL 可以对每次尝试的任务成功情况进行优化，不必为每个训练提示提供示范解法。

课件中的应用时间线： InstructGPT（2022）利用人类偏好和 PPO 改善指令遵循；DeepSeekMath（2024）提出 GRPO 用于数学推理；DeepSeek-R1（2025）利用可验证反馈训练推理。课件明确说明，R1 的训练流程结合了 RL 与监督训练阶段。

2.2 把一次回答拆成序列决策

RL 概念 单次回答生成中的对应物
状态 sts_tst​ 提示 xxx 与已生成前缀 y<ty_{<t}y<t​
动作 ata_tat​ 下一个 token yty_tyt​
策略 πθ(yt∣x,y<t)\pi_\theta(y_t\mid x,y_{<t})πθ​(yt​∣x,y<t​)
转移 将选出的 token 添加到前缀末尾
终止 生成结束符，或达到长度限制
奖励 常在完整回答结束后给出一个评分
πθ(y∣x)=∏t=1Tπθ(yt∣x,y<t).\pi_\theta(y\mid x)=\prod_{t=1}^{T}\pi_\theta(y_t\mid x,y_{<t}).πθ​(y∣x)=t=1∏T​πθ​(yt​∣x,y<t​).

补充解释：转移确定，为什么还有随机性？ 已知当前前缀和选出的 token 后，新前缀确定了。但策略可以随机采样不同 token，因此完整回答仍然是随机的。整段回答最后才获得评分时，还需要判断哪些早期 token 对结果有贡献。

2.3 RLHF 的三步流程

  1. 收集示范并做 SFT。 从提示数据中抽取问题，由标注者给出理想回答，训练监督策略。
  2. 收集比较并训练奖励模型。 对一个提示采样多个回答 A–D，由标注者排序，用偏好数据训练奖励模型。
  3. 根据奖励优化策略。 策略对提示生成回答，奖励模型评分，PPO 根据评分更新策略。

原图前两步的提示是“向一个 6 岁孩子解释登月”，示范回答从“有人登上了月球……”开始。比较阶段展示四个回答片段：A“解释重力……”，B“解释战争……”，C“月球是天然卫星……”，D“人们登上了月球……”。标注者的排序是 D>C>A=BD>C>A=BD>C>A=B，奖励模型学习这个偏好顺序。

第三步用“写一个关于青蛙的故事”展示策略生成“从前……”开头的回答，再由奖励模型评分并更新 PPO 策略。图中的关键数据流是：示范训练策略、比较训练奖励模型、奖励再指导策略改进。

2.4 人类偏好与可验证奖励

维度 RLHF 可验证奖励 RL（RLVR）
反馈来源 人类比较回答，再训练奖励模型评分 检查器直接评价结果
原例 回答是否有帮助、风格是否合适 数学答案检查、代码测试结果
适用优势 可表达较难写成程序的质量标准 可靠检查器存在时容易扩展
局限 偏好依赖标注者与标注指令 通过测试仍可能遗漏其他错误

奖励来源与优化算法是两项选择。 PPO 或 GRPO 都可以使用不同来源的奖励，不能把 RLHF 与 PPO、RLVR 与 GRPO 当作同义词。

2.5 REINFORCE、PPO、GRPO、DPO

方法 本周需要理解的核心
REINFORCE 提高高回报采样动作的概率，基线可降低梯度方差
PPO 用优势估计和裁剪的策略目标进行优化
GRPO 对同一提示生成多条回答，用组内相对表现估计优势，不需要独立价值模型
DPO 从固定数据集中的偏好与拒绝回答学习，不需要在线 rollout

DPO 从 RL 目标推导而来，属于偏好优化；课件特别将它与需要在线采样的 RL 算法区分。

读图时先辨认角色：qqq 是问题，ooo 是回答，rrr 是奖励，vvv 是价值预测，AAA 是优势估计。PPO 图中策略模型和价值模型参与训练，参考模型和奖励模型冻结。GAE 是图中利用奖励与价值形成优势估计的组件，本周不要求其公式。GRPO 用组内计算代替单独价值模型，用多个回答的得分衡量相对表现。

参考策略的 KL 惩罚用于抑制过大的策略偏移，使 RL 训练后的模型不要偏离训练前模型太多。

补充解释：价值与优势的直觉。 价值回答“从这里往后一般能有多好”；优势回答“这次选择相对通常水平好多少”。本周先理解这个比较关系，第 2 周的奖励基线会给出一个简单的数学版本。

2.6 与典型控制任务的比较

方面 典型控制任务 单次回答的 LLM RL
初始化 往往从简单策略开始 从大型预训练策略开始
动作 控制指令或游戏动作 大词表中的 token
动力学 物理系统或模拟器 确定地延长文本前缀
反馈 任务奖励，可能延迟 常在回答结束时评分
数据成本 与环境交互可能昂贵 生成长回答可能昂贵

双方都需要信用分配、探索和可靠评估。以上是典型情形，不是绝对边界：经典 RL 也可以使用预训练策略和终局奖励。

3. 智能体怎样与环境交互

来源：P27–29、P37。

在时刻 ttt，智能体收到状态 StS_tSt​，选择动作 AtA_tAt​；环境返回奖励 Rt+1R_{t+1}Rt+1​ 和下一状态 St+1S_{t+1}St+1​。由此得到轨迹：

S0,A0,R1,S1,A1,R2,S2,…S_0,A_0,R_1,S_1,A_1,R_2,S_2,\ldotsS0​,A0​,R1​,S1​,A1​,R2​,S2​,…

本周的奖励下标：AtA_tAt​ 对应 Rt+1R_{t+1}Rt+1​。 第 2 周 Bandit 改用 AtA_tAt​ 对应 RtR_tRt​，含义相同，只是记号约定不同。

大写 S,A,RS,A,RS,A,R 表示随机变量，小写 s,a,rs,a,rs,a,r 表示具体取值。智能体与环境的边界由建模者选择，例如回收机器人的“环境”可以包括它自己的身体。

3.1 回合任务与持续任务

  • 回合任务（Episodic task） 有自然终点，例如一局棋结束。一次完整交互称为一个 episode。
  • 持续任务（Continuing task） 没有自然终点，例如持续运行的过程控制。

3.2 状态不一定等于当前观测

状态表示应保留预测动作后果需要的信息；观测可能只包含其中一部分。课件的例子是：单张相机图像可能看不出速度。

如果两种情形在当前输入里看起来一样，却需要不同动作，就应考虑更多观测、历史、记忆或学习得到的特征。策略与价值函数都以状态表示为输入，表示不足会同时影响决策和预测。

补充解释。 两张相同位置的汽车照片，一张可能对应汽车正在靠近障碍物，另一张可能对应正在远离。把位置当成全部状态，会丢失选择制动动作所需的信息。这个例子补充说明课件的“单帧隐藏速度”。

3.3 RL 系统的四个常用组成部分

组成 回答的问题
策略 Policy 现在如何选动作？
奖励信号 Reward signal 这次交互得了多少分？目标是什么？
价值函数 Value function 往后预计还能累积多少奖励？
模型 Model，可选 动作之后环境会发生什么？

最终决定行为的是策略，其他部分可以帮助构造或改进策略。价值函数预测未来回报，环境模型预测下一状态和奖励，二者不能混淆。

4. 奖励、回报、策略、价值与模型

来源：P30–38。

4.1 奖励与回报

奖励评价一次转移，**回报（Return）**汇总之后一段时间的奖励。一个在时刻 TTT 结束的回合，未折扣回报为：

Gt=Rt+1+Rt+2+⋯+RT.G_t=R_{t+1}+R_{t+2}+\cdots+R_T.Gt​=Rt+1​+Rt+2​+⋯+RT​.

智能体最大化期望回报。国际象棋可以设为胜利得 1，其他结局得 0，终局前奖励全为 0。奖励设计规定了优化目标；学习则需要把最后的结果归因到之前的选择，这称为信用分配（Credit assignment）。

4.2 折扣如何改变选择

Gt=∑k=0T−t−1γkRt+k+1,γ∈[0,1].G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1},\qquad\gamma\in[0,1].Gt​=k=0∑T−t−1​γkRt+k+1​,γ∈[0,1].

最近的奖励系数是 1，再下一个是 γ\gammaγ，再下一个是 γ2\gamma^2γ2。有限回合可以使用 γ=1\gamma=1γ=1；持续任务通常考虑无穷和。在奖励有界且 γ<1\gamma<1γ<1 时，无穷折扣回报有限。

原例（P31）： 两个动作分别产生奖励序列 A：(2,0,0)(2,0,0)(2,0,0)，B：(0,0,3)(0,0,3)(0,0,3)，然后结束。

折扣因子 G0(A)G_0(A)G0​(A) G0(B)G_0(B)G0​(B) 哪个回报更高
γ=0.9\gamma=0.9γ=0.9 2 3×0.92=2.433\times0.9^2=2.433×0.92=2.43 B
γ=0.5\gamma=0.5γ=0.5 2 3×0.52=0.753\times0.5^2=0.753×0.52=0.75 A

折扣会改变目标本身，不只是为了让计算方便。B 的奖励在第三个时间位置，因此乘 γ2\gamma^2γ2，不是 γ3\gamma^3γ3。

4.5 为什么要学习价值

即时奖励相同的选择，可能有完全不同的长期后果。价值函数让智能体在看到完整结果之前，就能比较动作。它需要从连续经验中估计，并随着证据更新；策略改变时，未来行为也变了，原先的价值估计可能需要调整。

4.6 环境模型、学习与规划

模型预测动作后果，例如下一状态和奖励的分布。学习可以更新策略、价值，也可以学习环境模型。规划使用模型推演未来转移。

  • 无模型方法（Model-free）：学习有用的价值或策略，不使用显式状态转移模型来规划。
  • 基于模型的方法（Model-based）：使用已知或学到的模型。模拟器也可以通过采样提供预测的转移。

补充解释：神经网络不等于这里的“环境模型”。 用神经网络估计 V(s)V(s)V(s)，得到的是价值预测器。只有它预测环境后果并用于相应规划时，才属于这里讨论的环境模型用途。

4.7 不学价值函数，也能搜索策略

课件给出一种进化式的整策略搜索方式：固定一个候选策略，让它完成整段任务；比较完整运行的总奖励；保留成功策略并产生变体。

整策略评分 在交互中学习价值
评价完整行为的总表现 使用中间状态和具体转移的信息
可以没有价值函数 把学到的预测用于多个决策

整策略评分可能没有利用轨迹内部的详细结构。价值学习可以利用这些信息提高学习效率，但价值函数不是 RL 问题本身的必需条件。

5. 完整例子：井字棋如何从对局学习

来源：P39–47。这是本周最值得反复读的例子。

5.1 任务与对手

井字棋在 3×33\times33×3 棋盘进行，双方轮流落 X 或 O，横、竖或斜线连成三个同样符号者获胜；棋盘填满而无人连线则为平局。课件 P40 的棋盘示例中，X 在主对角线上连成三子。

我们执 X，对手策略固定但不完美，并且事先未知。固定的意思是对手的决策规律不随训练变化，并不意味着对手每次都必须采取确定性动作。目标是最大化战胜这个对手的概率，暂时把平局与失败都记为 0。

思路 需要什么，以及会优化什么
Minimax，极小化极大 防备对手最强的应对，可能放过利用这个具体对手失误的机会
动态规划 如果知道对手每种局面的走法概率，可以针对该模型优化
从对局中学习 不预先知道对手完整模型，通过经验识别更容易获胜的局面

补充解释。 对最强对手稳保不败，和对某个会失误的对手尽可能多赢，是不同的目标。某条有风险的走法可能会被完美对手惩罚，却能经常诱使实际对手犯错。

5.2 状态、动作与价值表

状态记录棋盘和轮到谁；轮到我方时，合法动作是在空格落 X。初始价值表为：

状态 初始 V(s)V(s)V(s)
X 获胜的终局 1
X 失败或平局的终局 0
尚未结束的局面 0.5

使用 γ=1\gamma=1γ=1。非终局的价值估计表示从该局面继续下去获胜的概率，初值 0.5 只是猜测，并不是已验证的胜率。学习后可能上升，也可能下降。

这里采用终局表项存分数的约定：终局胜利存 1，不再额外给一次胜利奖励。 这与前文“价值等于剩余未来奖励”的通常约定不同，见第 5.7 节。

5.3 怎么选动作，怎么看原图

智能体根据规则枚举自己的合法走法，查看落子后棋盘对应的价值。多数时候选择价值最大的后继局面，称为贪心动作；少数时候尝试其他走法，称为探索动作。

图中实线是本局实际走过的路径，虚线是考虑过但未选择的路径，星号表示当前估计最佳的走法。读图顺序如下：

  1. 起点为 aaa，对手行动后到 bbb；我方选择了带星号的 ccc，属于贪心动作。之后用 ccc 的价值更新之前存储的 aaa。
  2. 对手使棋盘到达 ddd，我方虽然估计 e∗e^*e∗ 更好，却选择了 eee，属于探索。本例跳过与这次探索动作对应的备份。
  3. 对手行动后到 fff，我方选择 g∗g^*g∗。这次贪心选择让较后局面的价值向前更新 eee。

红色弯箭头表示把后面的价值估计用于修正前面的估计，称为价值备份（Backup）。它表示信息回传，不表示棋子倒着走。

这里的备份连接我方落子后的两个已存局面，中间跨过对手的回应与我方下一次落子。不要把它机械理解成每一次单方落子后都做相同更新。

5.4 一步价值更新

在相关的贪心动作之后，用较后局面 s′s's′ 的价值更新较早局面 sss：

部分 解释
V(s)V(s)V(s) 之前对较早局面胜率的估计
V(s′)V(s')V(s′) 这次实际后续局面提供的新预测目标
V(s′)−V(s)V(s')-V(s)V(s′)−V(s) 两个预测之间的差，也就是本次修正的依据

原例（P43）： V(s)=0.50V(s)=0.50V(s)=0.50，V(s′)=0.80V(s')=0.80V(s′)=0.80，α=0.10\alpha=0.10α=0.10。

新估计向 0.80 前进了差距的 10%，而不是直接替换成 0.80。因为 V(s′)V(s')V(s′) 也只是估计，对手策略还可能是随机的，一条后续路径不能代表所有可能。

5.5 完整学习流程

  1. 初始化价值表，固定胜、负、平终局对应的结果分数。
  2. 轮到我方时，利用规则检查合法动作，查询各个落子后局面的价值。
  3. 通常选择最高价值的结果，偶尔探索其他动作。
  4. 对于贪心动作，将前一个已存局面的估计向新局面的估计备份；跳过与探索动作对应的备份。
  5. 不断与对手对局，保留并更新同一张价值表。

课件的目的不是搜索完整博弈树，而是用经验改进价值表，让价值表指导下一步选择。它知道棋规，能够预测自己落子后的棋盘，却不需要预先知道对手的完整策略。

5.6 探索之后到底该不该更新

两种做法对应不同的预测目标：

做法 希望估计的后续行为
只进行相关的贪心备份 后续采取贪心行为时的表现
每步都备份，包括探索 实际保留探索的行为所产生的表现

如果一直保留探索，两者的胜率可以不同。实际使用时还会随机尝试，还是全部按贪心执行，会影响哪个预测更相关。

补充解释。 “本例跳过某次探索备份”不是“强化学习不能利用探索数据”。它在说明：价值必须对应某一种后续策略。后面的 on-policy 与 off-policy 方法会系统处理行为策略和预测目标的关系。

5.7 终局分数的两种约定，不能混用

来源：P41、P47。胜利时，两种记法都应让前一状态的目标为 1：

记分方法，γ=1\gamma=1γ=1 最后奖励 存储的终局值 备份目标
本例：分数存入终局表项 0 1 0+1=10+1=10+1=1
通常的未来回报约定 1 0 1+0=11+0=11+0=1

游戏已结束时，通常定义下没有剩余未来奖励，所以终局价值为 0。井字棋教学例子把结果直接存入终局表项，是另一种记分方式。如果同时给胜利奖励 1，又令目标额外加上终局值 1，就会得到 2，重复计算胜利。

5.8 自我对弈改变了学习目标

上面假定只我方学习、对手固定。双方同时学习时，昨天的对手与今天的对手不同，胜率随之改变，旧价值可能失准。

完美井字棋双方对弈会平局，但这一事实不能证明任意自我对弈算法都会收敛。用固定的参考对手评估，可以帮助区分自身进步与训练对手变化带来的影响。

7. 与 LLM、Bandit 和后续课程的联系

来源：P18、P51–52。

回看 LLM：策略是下一个 token 或工具动作的概率；奖励来自偏好、验证器或任务结果；价值与优势帮助分配信用和比较决策；采样回答决定训练能发现哪些解法。评估时还要看留出的任务表现，不能只看被优化的奖励是否变大。

多臂老虎机（Multi-armed bandit）去掉动作对未来决策状态的影响，专门研究在未知奖励下怎样平衡探索和利用。只能看到选中动作的奖励，持续选择当前估计最优的动作，会让低估的动作一直没有机会被纠正。

这里改用 Bandit 下标：动作 AtA_tAt​ 后的奖励为 RtR_tRt​。

q∗(a)=E[Rt∣At=a],q∗=max⁡aq∗(a).q_*(a)=\mathbb E[R_t\mid A_t=a],\qquad q_*=\max_a q_*(a).q∗​(a)=E[Rt​∣At​=a],q∗​=amax​q∗​(a).

与始终选择最佳动作相比，TTT 轮损失的期望奖励称为遗憾：

Regret⁡(T)=Tq∗−E[∑t=1TRt].\operatorname{Regret}(T)=Tq_*-\mathbb E\left[\sum_{t=1}^T R_t\right].Regret(T)=Tq∗​−E[t=1∑T​Rt​].

第 2 周会比较样本均值、ϵ\epsilonϵ-greedy 和 UCB，并学习直接优化动作概率的梯度 Bandit。课程随后进入 MDP 与 Bellman 方程，再发展价值方法、策略梯度、函数近似、规划、离线 RL 和语言模型应用。

9.2 先做题，再展开答案

题 1。 送货机器人连续收到 (0,0,1)(0,0,1)(0,0,1)，γ=0.9\gamma=0.9γ=0.9。从第一次行动前看，回报是多少？

参考答案
G0=0+0.9×0+0.92×1=0.81.G_0=0+0.9\times0+0.9^2\times1=0.81.G0​=0+0.9×0+0.92×1=0.81.

最先的转弯没有即时奖励，但影响能否最终送达，因而需要信用分配。

题 2。 某状态下两个动作价值分别是 2 和 4.5，策略以 0.2、0.8 的概率选它们，状态价值是多少？

参考答案
vπ(s)=0.2×2+0.8×4.5=4.v_\pi(s)=0.2\times2+0.8\times4.5=4.vπ​(s)=0.2×2+0.8×4.5=4.

这里是对动作价值取策略加权平均，不是直接取最大值。取最大值会对应另一种动作选择规则。

题 3。 V(s)=0.6V(s)=0.6V(s)=0.6、目标 V(s′)=0.2V(s')=0.2V(s′)=0.2、α=0.25\alpha=0.25α=0.25，一次井字棋备份后是多少？

参考答案
Vnew(s)=0.6+0.25(0.2−0.6)=0.5.V_{\text{new}}(s)=0.6+0.25(0.2-0.6)=0.5.Vnew​(s)=0.6+0.25(0.2−0.6)=0.5.

误差为负，所以估计下降。更新结果应处于旧估计 0.6 与目标 0.2 之间。

题 4。 胜利时奖励设为 1，终局表项也设为 1，使用 R+γVR+\gamma VR+γV 且 γ=1\gamma=1γ=1 更新，哪里有问题？

参考答案

目标变成 2，重复记分。选择“奖励 1、终局未来价值 0”，或本例的“奖励 0、终局分数 1”。

题 5。 “只要给策略网络训练，就属于 model-based RL”是否正确？“RL 必须每次在线与真实世界交互”是否正确？

参考答案

都不正确。这里的 model-based 指利用环境后果模型进行规划，而非泛指拥有神经网络。RL 也可以使用离线经验或模拟交互。

题 6。 只在贪心选择后备份与每次选择后都备份，为什么可能得到不同价值？

参考答案

它们希望描述的后续策略不同：前者面向贪心继续，后者面向实际带探索的继续。持续探索会改变未来胜率，价值必须说明对应哪一种行为。

题 7。 语言生成的前缀转移是确定的，是否说明策略不需要探索？

参考答案

不说明。策略仍要在很多候选 token 和回答之间选择。采样不同回答能发现不同解法，最终评分可以帮助提高成功行为的概率。
