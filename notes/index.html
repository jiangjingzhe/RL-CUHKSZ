CSC6129 强化学习：中文自学笔记

这套笔记把每周课件整理为可以独立阅读的中文章节，保留原课件的知识点、公式、数值例子、实验图和参考文献，并补充推导、易错提醒与自测答案。

开始阅读：第 1 周：强化学习导论。 复习第二周时，可以直接进入多臂老虎机。

怎样用它高效自学

  1. 第一次学习： 先读章首目标和正文，每个公式都先读懂符号与假设，再亲手重算“原例”。LLM 预览无需本周掌握全部算法细节。
  2. 当次学完： 不看笔记回答章节自测，答完再展开答案。在章末记录卡住的概念与错因。
  3. 隔天复习： 先看自己记录的问题，重新计算做错的例子，再对照公式回忆卡。
  4. 一周后： 尝试不用原文，用送货机器人、井字棋和两臂 Bandit 讲清主要概念。讲不通的地方再回对应节。

以上是建议使用方式，不是课程要求。学习是否扎实，以能解释、能计算、能说出适用条件为准。

格式与标记

Markdown 是可维护的原稿：一周一文件，公式采用 LaTeX，图片与引用采用相对路径。移动文件夹时，请保留整个 notes 目录的结构。可在支持 Markdown 数学公式的阅读器中阅读，例如已有的 Obsidian 或 Typora；也可以通过 GitHub Pages 在线阅读。原始课件 PDF 只保留在本地，网页所需的原页图片已包含在 assets 目录中。

同目录的 index.html 是便于直接打开的离线阅读入口，包含目录导航和已排版公式。HTML 由 Markdown 生成，日后修改 Markdown，再重新生成阅读版，避免维护两份内容。

  • 来源 Pn： 对应原 PDF 的实际页面序号。
  • 原例 / 原实验： 保留课件给定的设定、数值和条件。
  • 补充解释 / 补充推导 / 自测： 为帮助学习添加，不能当作教师原话或考试范围说明。
  • 课件参考文献： 保留书目信息，未将未读的整篇论文内容扩充为授课知识。
  • 原图： 来自用户提供的课件，正文有中文读图说明，图库保留全部页面。

第 2 周 PDF 正文页脚是 1/47–47/47，附录另起 1/5–5/5。这里统一使用实际 PDF 页码 1–52，以免“第 1 页”指代两处。第 1 周文件为 54 页，共计 106 页。

连续的目录页、封面和章节分隔页在正文合并处理，但在逐页对应表中各有记录。图中被裁剪、实际不可见的隐藏 PDF 文字不当作课件内容扩写。

后续维护

每新增一周，复制章节模板为 week03.md 等文件，填入源文件与页数，按“概念、公式、原例、补充说明、自测”的顺序整理。保留原课件文件；新图片使用 assets/week03/page-01.jpg 一类稳定名称。更新入口、术语表、逐页对应表和来源清单。

原材料修订时，先检查对应页，更新其正文和图片，再重新生成离线阅读版。不要仅替换 PDF，却继续保留旧例子的数字。当前来源的文件名、页数与 SHA-256 指纹记录在 sources.json，便于识别版本变化。

构建与检查方法见 维护说明。这份说明只供以后维护，日常学习不需要阅读。
