# 笔记维护说明

[返回学习入口](README.md)

日常学习直接打开 `index.html`。本页供修改笔记或加入新一周材料时使用。

## 文件分工

- `week01.md`、`week02.md`、`week03.md`、`week04-05.md`、`week06.md`：每周内容的唯一原稿。
- `week02-appendix.md`：完整证明，与正文互相链接。
- `README.md`：学习入口。生成时转换为 `index.html`。
- `glossary.md`：统一术语与符号，不重复维护整章解释。
- `coverage.md`、`source-pages.md`、`sources.json`：由 `tools/sources.py` 生成的溯源资料。
- `assets/weekXX/page-YY.jpg`：原 PDF 实际页面，正文和图库共用同一文件；这些图片是公开网页的原页素材。
- `*.html`：生成的阅读版，日常修改不要直接编辑。
- `reader.css`：离线阅读样式。
- `tools/build.mjs`：将 Markdown 和公式转换为离线 HTML。
- `vendor`：阅读与生成所需的公开组件，保留原许可证。公式使用 KaTeX 0.16.22；Markdown 使用随工作环境提供并复制到本目录的 Marked 组件。

## 只修改文字时

编辑对应 Markdown，再在 `notes` 目录运行：

```sh
node tools/build.mjs
```

需要 Node.js。构建脚本直接导入本目录的组件，不需要 npm 安装，也不需要联网。公式编译错误会使构建失败，以便发现未闭合或错误的 LaTeX。

迁移到其他机器后，使用该机器上的 `node` 即可；构建脚本不需要联网或安装 npm 依赖。

## 替换源课件或增加周次时

在拥有本地源 PDF 时保留源文件并核实变更。更新 `tools/sources.py` 中的来源列表、每一页到笔记节的映射与章节名称，再运行：

```sh
python3 tools/sources.py --render
```

需要 Python 3，以及 `pypdf`、`pypdfium2`、`Pillow`。不重新导出图片时可省略 `--render`。这个脚本生成页索引与图片，**不会自动替你阅读新课件并写中文笔记**。

合并课件使用 `week04-05` 这类来源编号，并保留实际 PDF 页码；不重复计算为两份源文件。仅生成新增来源图片可运行 `python3 tools/sources.py --render-source 04-05 --render-source 06`，原有 `--render` 仍会重新导出所有来源。

每新增一章，还需更新 `tools/build.mjs` 的 `pages` 列表、学习入口与术语表，之后重建 HTML。章节模板提供内容结构。

## 内容检查约定

每次检查源页与正文是否匹配，特别是例子数据、实验轴、参数、奖励范围、下标和附录。只写原课件实际展示的内容；扩展说明标明为补充。不要把初值、学习率、探索率或不同实验条件合并成一个设定。

构建后检查页面中的公式、表格和图片，打开几道折叠答案，并检查窄窗口中的横向滚动。页面无需网络；保留整个目录即可移动到其他机器。
