## 1. 强化学习要解决什么问题

来源：P3、P20–26。

### 1.1 定义里的每个词都重要

**强化学习（Reinforcement Learning，RL）**：智能体通过经验学习如何行动，目标是最大化**期望累积奖励**。

| 关键词 | 含义 |
| --- | --- |
| 智能体 Agent | 作出决策的部分，不一定是整个机器人 |
| 经验 Experience | 做过什么、进入什么情境、得到什么反馈 |
| 学习行动 | 经验会改变以后的决策规则 |
| 奖励 Reward | 用数值评价结果，不一定告诉智能体正确动作 |
| 累积 Cumulative | 关心一段时间的总收益，当前有代价的动作可能以后有益 |
| 期望 Expected | 在随机环境或随机策略下，关注平均意义上的表现 |

动作既影响以后获得奖励的机会，也影响之后收集到的经验。这让“学习什么”和“接下来做什么”互相影响。

“RL”也有三个使用层次：它可以指**决策问题**，指从经验学习策略、价值或模型的**方法**，也可以指研究这些问题、算法及其性质的**领域**。不要因为某个算法没有在线试错，就仅凭这一点把它排除在整个 RL 理论框架之外。

### 1.2 原例：机器人导航中的学习与规划

| 做法 | 输入与工作方式 |
| --- | --- |
| 从经验学习 | 机器人尝试移动，根据奖励学会到达目标 |
| 规划 Planning | 给定地图和运动规则，计算到达目标的路线 |
| 基于模型的 RL | 先从经验学习运动模型，再用模型规划路线 |

动态规划（Dynamic Programming，DP）利用已知的状态转移和奖励模型计算价值与策略。它不必通过真实交互学习模型，但其价值函数和策略改进思想是很多 RL 算法的基础。

### 1.3 从完整智能体的角度理解任务

智能体感知情境、采取动作，并通过反馈评价目标完成情况。感知、预测和规划都服务于这个交互过程。

**原例：电池管理智能体。** 它读取电量并请求充电；机器人其余部分都可以算入环境。所谓“完整智能体”，强调感知、行动、目标组成的闭环，不要求智能体包含整台物理机器。

### 1.4 与其他学习设置的关系

| 设置 | 典型学习信号 |
| --- | --- |
| 监督学习 | 正确标签或示范 |
| 无监督学习 | 数据中可发现的结构 |
| 强化学习 | 与动作及其后果关联的奖励 |

RL 内部可以使用监督学习，例如拟合价值函数或环境模型。**在线 RL** 在学习过程中收集新交互；**离线 RL** 从已有数据集学习策略，困难之一是未出现过的动作缺乏可靠证据。训练也可以在模拟环境中进行，因此 RL 并不要求训练期间在真实系统上试验。

### 1.5 原例：探索与利用

| 动作 | 已观察奖励的均值 | 尝试次数 |
| --- | ---: | ---: |
| A | 0.6 | 100 |
| B | 0.5 | 2 |

**利用（Exploitation）**：按当前估计，选择较好的 A 获取奖励。**探索（Exploration）**：尝试 B，获得可能改善未来决策的信息。

只剩一次决策时，按样本均值选择 A 更有理由；如果还要决策很多次，了解 B 可能值得。**表格不足以唯一确定最优选择**：还需要考虑奖励的不确定性、先验信息和剩余轮数。B 的均值低，不代表它的真实表现一定差；只观察两次，结论还不稳固。

> **补充解释：探索的价值从哪里来？**
> 这次试 B 可能少赚，但若发现 B 实际更好，后面很多次选择都能受益。为了未来的学习收益，当前可以接受一定的奖励损失。

### 1.6 课件列举的任务

| 智能体 | 决策 | 长期目标 |
| --- | --- | --- |
| 游戏玩家 | 下一步走哪里 | 赢下整局 |
| 移动机器人 | 移动还是充电 | 在能量和故障约束下完成任务 |
| 工厂控制器 | 使用哪些运行参数 | 高效生产有用的产品 |
| 语言模型 | 下一个 token 或工具动作 | 生成成功的回答或完成任务 |

这些任务都可能存在多步依赖和延迟反馈。

**原例：送货机器人（P25）。** 简化任务只在交付时奖励 +1，其他时候奖励 0。

| 当前情境 | 动作 | 下一情境 | 奖励 |
| --- | --- | --- | ---: |
| 岔路口 | 转入走廊 | 办公室附近 | 0 |
| 办公室附近 | 靠近门口 | 办公室门口 | 0 |
| 办公室门口 | 交付包裹 | 任务完成 | +1 |

岔路口选择不同方向，会改变后续位置与可选动作，这是**顺序依赖**。奖励最后才出现，但之前转弯也有贡献，这是**延迟奖励与信用分配**问题。

**原例：回收机器人（P26）。** 这个模型只保留电量，暂时抽象掉位置和导航。

- 智能体：决策控制器；环境：机器人身体和周围世界。
- 状态：高电量或低电量。
- 动作：搜索空罐（平均收获多，但耗电）、等待别人送罐（收获较少，但省电）、充电（只在低电量时可选）。
- 奖励：每收集一个罐子 +1；电量耗尽、需要救援时 −3；其他情况为 0。
- 策略：根据电量选择动作的规则。

充电当下奖励为 0，却能支持后续继续收集空罐。目标是累积收益，而不是每一步都得到最多罐子。

## 2. 为什么语言模型也用强化学习

来源：P4–11。本节是算法预览，详细推导留待后续周。

### 2.1 预训练、SFT 和 RL 的目标

预训练学习预测大规模文本中的 token；监督微调（SFT）模仿选好的示范；RL 后训练则评价模型**自己生成的回答**，根据反馈调整行为。

设提示为 $x$，回答为 $y$，策略参数为 $\theta$，数据分布为 $D$。

$$
\text{SFT}:\quad \max_\theta\;\mathbb E_{(x,y)\sim D}[\log\pi_\theta(y\mid x)].
$$

$$
\text{RL}:\quad \max_\theta\;\mathbb E_{x\sim D,\;y\sim\pi_\theta(\cdot\mid x)}[r(x,y)].
$$

SFT 增大数据集里示范回答的概率；RL 增大自己采样到的高奖励回答所对应行为的倾向。有些任务的答案容易验证，却难以逐条给出优质示范。预训练模型提供了有用的初始策略，RL 可以对每次尝试的任务成功情况进行优化，不必为每个训练提示提供示范解法。

**课件中的应用时间线：** InstructGPT（2022）利用人类偏好和 PPO 改善指令遵循；DeepSeekMath（2024）提出 GRPO 用于数学推理；DeepSeek-R1（2025）利用可验证反馈训练推理。课件明确说明，R1 的训练流程结合了 RL 与监督训练阶段。

### 2.2 把一次回答拆成序列决策

| RL 概念 | 单次回答生成中的对应物 |
| --- | --- |
| 状态 $s_t$ | 提示 $x$ 与已生成前缀 $y_{<t}$ |
| 动作 $a_t$ | 下一个 token $y_t$ |
| 策略 | $\pi_\theta(y_t\mid x,y_{<t})$ |
| 转移 | 将选出的 token 添加到前缀末尾 |
| 终止 | 生成结束符，或达到长度限制 |
| 奖励 | 常在完整回答结束后给出一个评分 |

$$
\pi_\theta(y\mid x)=\prod_{t=1}^{T}\pi_\theta(y_t\mid x,y_{<t}).
$$

> **补充解释：转移确定，为什么还有随机性？**
> 已知当前前缀和选出的 token 后，新前缀确定了。但策略可以随机采样不同 token，因此完整回答仍然是随机的。整段回答最后才获得评分时，还需要判断哪些早期 token 对结果有贡献。

### 2.3 RLHF 的三步流程

![原课件 P7：RLHF 三步流程](assets/week01/page-07.jpg)

1. **收集示范并做 SFT。** 从提示数据中抽取问题，由标注者给出理想回答，训练监督策略。
2. **收集比较并训练奖励模型。** 对一个提示采样多个回答 A–D，由标注者排序，用偏好数据训练奖励模型。
3. **根据奖励优化策略。** 策略对提示生成回答，奖励模型评分，PPO 根据评分更新策略。

原图前两步的提示是“向一个 6 岁孩子解释登月”，示范回答从“有人登上了月球……”开始。比较阶段展示四个回答片段：A“解释重力……”，B“解释战争……”，C“月球是天然卫星……”，D“人们登上了月球……”。标注者的排序是 $D>C>A=B$，奖励模型学习这个偏好顺序。

第三步用“写一个关于青蛙的故事”展示策略生成“从前……”开头的回答，再由奖励模型评分并更新 PPO 策略。图中的关键数据流是：示范训练策略、比较训练奖励模型、奖励再指导策略改进。

### 2.4 人类偏好与可验证奖励

| 维度 | RLHF | 可验证奖励 RL（RLVR） |
| --- | --- | --- |
| 反馈来源 | 人类比较回答，再训练奖励模型评分 | 检查器直接评价结果 |
| 原例 | 回答是否有帮助、风格是否合适 | 数学答案检查、代码测试结果 |
| 适用优势 | 可表达较难写成程序的质量标准 | 可靠检查器存在时容易扩展 |
| 局限 | 偏好依赖标注者与标注指令 | 通过测试仍可能遗漏其他错误 |

**奖励来源与优化算法是两项选择。** PPO 或 GRPO 都可以使用不同来源的奖励，不能把 RLHF 与 PPO、RLVR 与 GRPO 当作同义词。

### 2.5 REINFORCE、PPO、GRPO、DPO

| 方法 | 本周需要理解的核心 |
| --- | --- |
| REINFORCE | 提高高回报采样动作的概率，基线可降低梯度方差 |
| PPO | 用优势估计和裁剪的策略目标进行优化 |
| GRPO | 对同一提示生成多条回答，用组内相对表现估计优势，不需要独立价值模型 |
| DPO | 从固定数据集中的偏好与拒绝回答学习，不需要在线 rollout |

DPO 从 RL 目标推导而来，属于偏好优化；课件特别将它与需要在线采样的 RL 算法区分。

![原课件 P10：PPO 与 GRPO 的组件](assets/week01/page-10.jpg)

读图时先辨认角色：$q$ 是问题，$o$ 是回答，$r$ 是奖励，$v$ 是价值预测，$A$ 是优势估计。PPO 图中策略模型和价值模型参与训练，参考模型和奖励模型冻结。GAE 是图中利用奖励与价值形成优势估计的组件，本周不要求其公式。GRPO 用组内计算代替单独价值模型，用多个回答的得分衡量相对表现。

参考策略的 KL 惩罚用于抑制过大的策略偏移，使 RL 训练后的模型不要偏离训练前模型太多。

> **补充解释：价值与优势的直觉。**
> 价值回答“从这里往后一般能有多好”；优势回答“这次选择相对通常水平好多少”。本周先理解这个比较关系，第 2 周的奖励基线会给出一个简单的数学版本。

### 2.6 与典型控制任务的比较

| 方面 | 典型控制任务 | 单次回答的 LLM RL |
| --- | --- | --- |
| 初始化 | 往往从简单策略开始 | 从大型预训练策略开始 |
| 动作 | 控制指令或游戏动作 | 大词表中的 token |
| 动力学 | 物理系统或模拟器 | 确定地延长文本前缀 |
| 反馈 | 任务奖励，可能延迟 | 常在回答结束时评分 |
| 数据成本 | 与环境交互可能昂贵 | 生成长回答可能昂贵 |

双方都需要信用分配、探索和可靠评估。以上是典型情形，不是绝对边界：经典 RL 也可以使用预训练策略和终局奖励。

## 3. 智能体怎样与环境交互

来源：P27–29、P37。

![原课件 P27：智能体与环境的接口](assets/week01/page-27.jpg)

在时刻 $t$，智能体收到状态 $S_t$，选择动作 $A_t$；环境返回奖励 $R_{t+1}$ 和下一状态 $S_{t+1}$。由此得到轨迹：

$$
S_0,A_0,R_1,S_1,A_1,R_2,S_2,\ldots
$$

**本周的奖励下标：$A_t$ 对应 $R_{t+1}$。** 第 2 周 Bandit 改用 $A_t$ 对应 $R_t$，含义相同，只是记号约定不同。

大写 $S,A,R$ 表示随机变量，小写 $s,a,r$ 表示具体取值。智能体与环境的边界由建模者选择，例如回收机器人的“环境”可以包括它自己的身体。

### 3.1 回合任务与持续任务

- **回合任务（Episodic task）** 有自然终点，例如一局棋结束。一次完整交互称为一个 episode。
- **持续任务（Continuing task）** 没有自然终点，例如持续运行的过程控制。

### 3.2 状态不一定等于当前观测

状态表示应保留预测动作后果需要的信息；观测可能只包含其中一部分。课件的例子是：**单张相机图像可能看不出速度**。

如果两种情形在当前输入里看起来一样，却需要不同动作，就应考虑更多观测、历史、记忆或学习得到的特征。策略与价值函数都以状态表示为输入，表示不足会同时影响决策和预测。

> **补充解释。** 两张相同位置的汽车照片，一张可能对应汽车正在靠近障碍物，另一张可能对应正在远离。把位置当成全部状态，会丢失选择制动动作所需的信息。这个例子补充说明课件的“单帧隐藏速度”。

### 3.3 RL 系统的四个常用组成部分

| 组成 | 回答的问题 |
| --- | --- |
| 策略 Policy | 现在如何选动作？ |
| 奖励信号 Reward signal | 这次交互得了多少分？目标是什么？ |
| 价值函数 Value function | 往后预计还能累积多少奖励？ |
| 模型 Model，可选 | 动作之后环境会发生什么？ |

最终决定行为的是策略，其他部分可以帮助构造或改进策略。价值函数预测未来回报，环境模型预测下一状态和奖励，二者不能混淆。

## 4. 奖励、回报、策略、价值与模型

来源：P30–38。

### 4.1 奖励与回报

**奖励**评价一次转移，**回报（Return）**汇总之后一段时间的奖励。一个在时刻 $T$ 结束的回合，未折扣回报为：

$$
G_t=R_{t+1}+R_{t+2}+\cdots+R_T.
$$

智能体最大化期望回报。国际象棋可以设为胜利得 1，其他结局得 0，终局前奖励全为 0。奖励设计规定了优化目标；学习则需要把最后的结果归因到之前的选择，这称为**信用分配（Credit assignment）**。

### 4.2 折扣如何改变选择

$$
G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1},\qquad\gamma\in[0,1].
$$

最近的奖励系数是 1，再下一个是 $\gamma$，再下一个是 $\gamma^2$。有限回合可以使用 $\gamma=1$；持续任务通常考虑无穷和。在奖励有界且 $\gamma<1$ 时，无穷折扣回报有限。

**原例（P31）：** 两个动作分别产生奖励序列 A：$(2,0,0)$，B：$(0,0,3)$，然后结束。

| 折扣因子 | $G_0(A)$ | $G_0(B)$ | 哪个回报更高 |
| --- | ---: | ---: | --- |
| $\gamma=0.9$ | 2 | $3\times0.9^2=2.43$ | B |
| $\gamma=0.5$ | 2 | $3\times0.5^2=0.75$ | A |

折扣会改变目标本身，不只是为了让计算方便。B 的奖励在第三个时间位置，因此乘 $\gamma^2$，不是 $\gamma^3$。

> **补充推导：回报的递推形式。** 将第一项单独提出，可得 $G_t=R_{t+1}+\gamma G_{t+1}$。若持续任务满足 $|R_t|\le M$，则 $|G_t|\le M/(1-\gamma)$。前一个等式是理解后续 Bellman 方程的准备。

### 4.3 策略

确定性策略写成 $A_t=\pi(S_t)$。随机策略给出概率：

$$
\pi(a\mid s)=\Pr(A_t=a\mid S_t=s),\qquad
\pi(a\mid s)\ge0,\qquad \sum_{a\in\mathcal A(s)}\pi(a\mid s)=1.
$$

**原例：** 低电量时，以 0.8 的概率充电、0.2 的概率搜索。策略可以是一张查找表，也可以是参数模型 $\pi_\theta$。执行固定策略是在选动作；学习策略则改变这个选择规则。

### 4.4 状态价值与动作价值

$$
v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s].
$$

状态价值表示：从状态 $s$ 出发，之后遵循 $\pi$，预计能获得多少回报。

$$
q_\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].
$$

动作价值表示：从 $s$ 出发，**先固定执行动作 $a$**，之后遵循 $\pi$，预计能获得多少回报。

$$
v_\pi(s)=\sum_a\pi(a\mid s)q_\pi(s,a).
$$

上式是在当前策略的动作概率下，对各种动作价值取平均。价值依赖策略、环境、奖励定义与折扣因子。课件用大写 $V(s)$、$Q(s,a)$ 表示学到的估计，不应默认等于真实价值。

**原例（P34）：** 这是一个独立的假想机器人，数值与 P26 回收机器人无关。动作后的行为固定为同一个策略 $\pi$。

| 动作 | 即时奖励 | 下一状态的价值 |
| --- | ---: | ---: |
| 搜索 Search | +2 | 0 |
| 充电 Recharge | 0 | 5 |

在确定性转移且 $\gamma=0.9$ 时：

$$
q_\pi(s,\text{search})=2+0.9\times0=2,
$$

$$
q_\pi(s,\text{recharge})=0+0.9\times5=4.5.
$$

充电即时奖励更低，但动作价值更高。**下一状态的价值 5 已概括之后的奖励，不能再把这些奖励重复加一遍。**

### 4.5 为什么要学习价值

即时奖励相同的选择，可能有完全不同的长期后果。价值函数让智能体在看到完整结果之前，就能比较动作。它需要从连续经验中估计，并随着证据更新；策略改变时，未来行为也变了，原先的价值估计可能需要调整。

### 4.6 环境模型、学习与规划

模型预测动作后果，例如下一状态和奖励的分布。**学习**可以更新策略、价值，也可以学习环境模型。**规划**使用模型推演未来转移。

- **无模型方法（Model-free）**：学习有用的价值或策略，不使用显式状态转移模型来规划。
- **基于模型的方法（Model-based）**：使用已知或学到的模型。模拟器也可以通过采样提供预测的转移。

> **补充解释：神经网络不等于这里的“环境模型”。** 用神经网络估计 $V(s)$，得到的是价值预测器。只有它预测环境后果并用于相应规划时，才属于这里讨论的环境模型用途。

### 4.7 不学价值函数，也能搜索策略

课件给出一种进化式的整策略搜索方式：固定一个候选策略，让它完成整段任务；比较完整运行的总奖励；保留成功策略并产生变体。

| 整策略评分 | 在交互中学习价值 |
| --- | --- |
| 评价完整行为的总表现 | 使用中间状态和具体转移的信息 |
| 可以没有价值函数 | 把学到的预测用于多个决策 |

整策略评分可能没有利用轨迹内部的详细结构。价值学习可以利用这些信息提高学习效率，但**价值函数不是 RL 问题本身的必需条件**。

## 5. 完整例子：井字棋如何从对局学习

来源：P39–47。这是本周最值得反复读的例子。

### 5.1 任务与对手

井字棋在 $3\times3$ 棋盘进行，双方轮流落 X 或 O，横、竖或斜线连成三个同样符号者获胜；棋盘填满而无人连线则为平局。课件 P40 的棋盘示例中，X 在主对角线上连成三子。

我们执 X，对手策略**固定但不完美**，并且事先未知。固定的意思是对手的决策规律不随训练变化，并不意味着对手每次都必须采取确定性动作。目标是最大化战胜这个对手的概率，暂时把平局与失败都记为 0。

| 思路 | 需要什么，以及会优化什么 |
| --- | --- |
| Minimax，极小化极大 | 防备对手最强的应对，可能放过利用这个具体对手失误的机会 |
| 动态规划 | 如果知道对手每种局面的走法概率，可以针对该模型优化 |
| 从对局中学习 | 不预先知道对手完整模型，通过经验识别更容易获胜的局面 |

> **补充解释。** 对最强对手稳保不败，和对某个会失误的对手尽可能多赢，是不同的目标。某条有风险的走法可能会被完美对手惩罚，却能经常诱使实际对手犯错。

### 5.2 状态、动作与价值表

状态记录棋盘和轮到谁；轮到我方时，合法动作是在空格落 X。初始价值表为：

| 状态 | 初始 $V(s)$ |
| --- | ---: |
| X 获胜的终局 | 1 |
| X 失败或平局的终局 | 0 |
| 尚未结束的局面 | 0.5 |

使用 $\gamma=1$。非终局的价值估计表示从该局面继续下去获胜的概率，初值 0.5 只是猜测，并不是已验证的胜率。学习后可能上升，也可能下降。

**这里采用终局表项存分数的约定：终局胜利存 1，不再额外给一次胜利奖励。** 这与前文“价值等于剩余未来奖励”的通常约定不同，见第 5.7 节。

### 5.3 怎么选动作，怎么看原图

智能体根据规则枚举自己的合法走法，查看落子后棋盘对应的价值。多数时候选择价值最大的后继局面，称为**贪心动作**；少数时候尝试其他走法，称为**探索动作**。

![原课件 P42：实际走法、探索走法与价值备份](assets/week01/page-42.jpg)

图中实线是本局实际走过的路径，虚线是考虑过但未选择的路径，星号表示当前估计最佳的走法。读图顺序如下：

1. 起点为 $a$，对手行动后到 $b$；我方选择了带星号的 $c$，属于贪心动作。之后用 $c$ 的价值更新之前存储的 $a$。
2. 对手使棋盘到达 $d$，我方虽然估计 $e^*$ 更好，却选择了 $e$，属于探索。本例跳过与这次探索动作对应的备份。
3. 对手行动后到 $f$，我方选择 $g^*$。这次贪心选择让较后局面的价值向前更新 $e$。

红色弯箭头表示把后面的价值估计用于修正前面的估计，称为**价值备份（Backup）**。它表示信息回传，不表示棋子倒着走。

这里的备份连接**我方落子后的两个已存局面**，中间跨过对手的回应与我方下一次落子。不要把它机械理解成每一次单方落子后都做相同更新。

### 5.4 一步价值更新

在相关的贪心动作之后，用较后局面 $s'$ 的价值更新较早局面 $s$：

$$
V(s)\leftarrow V(s)+\alpha\big[V(s')-V(s)\big],\qquad \alpha\in(0,1].
$$

| 部分 | 解释 |
| --- | --- |
| $V(s)$ | 之前对较早局面胜率的估计 |
| $V(s')$ | 这次实际后续局面提供的新预测目标 |
| $V(s')-V(s)$ | 两个预测之间的差，也就是本次修正的依据 |
| $\alpha$ | 学习步长，本次向目标靠近多少比例 |

**原例（P43）：** $V(s)=0.50$，$V(s')=0.80$，$\alpha=0.10$。

$$
V_{\text{new}}(s)=0.50+0.10(0.80-0.50)=0.53.
$$

新估计向 0.80 前进了差距的 10%，而不是直接替换成 0.80。因为 $V(s')$ 也只是估计，对手策略还可能是随机的，一条后续路径不能代表所有可能。

> **补充解释：为什么叫时序差分（Temporal Difference，TD）？**
> 更新依据来自先后两个时点的预测之差。这里用一个估计帮助更新另一个估计，体现了“自举”的思想；不必每次都等整局结果出现，才更新所有前面的位置。本例中间奖励为 0 且 $\gamma=1$，因此目标简化为后继价值。

### 5.5 完整学习流程

1. 初始化价值表，固定胜、负、平终局对应的结果分数。
2. 轮到我方时，利用规则检查合法动作，查询各个落子后局面的价值。
3. 通常选择最高价值的结果，偶尔探索其他动作。
4. 对于贪心动作，将前一个已存局面的估计向新局面的估计备份；跳过与探索动作对应的备份。
5. 不断与对手对局，保留并更新同一张价值表。

课件的目的不是搜索完整博弈树，而是用经验改进价值表，让价值表指导下一步选择。它知道棋规，能够预测自己落子后的棋盘，却不需要预先知道对手的完整策略。

### 5.6 探索之后到底该不该更新

两种做法对应不同的预测目标：

| 做法 | 希望估计的后续行为 |
| --- | --- |
| 只进行相关的贪心备份 | 后续采取贪心行为时的表现 |
| 每步都备份，包括探索 | 实际保留探索的行为所产生的表现 |

如果一直保留探索，两者的胜率可以不同。实际使用时还会随机尝试，还是全部按贪心执行，会影响哪个预测更相关。

> **补充解释。** “本例跳过某次探索备份”不是“强化学习不能利用探索数据”。它在说明：价值必须对应某一种后续策略。后面的 on-policy 与 off-policy 方法会系统处理行为策略和预测目标的关系。

### 5.7 终局分数的两种约定，不能混用

来源：P41、P47。胜利时，两种记法都应让前一状态的目标为 1：

| 记分方法，$\gamma=1$ | 最后奖励 | 存储的终局值 | 备份目标 |
| --- | ---: | ---: | ---: |
| 本例：分数存入终局表项 | 0 | 1 | $0+1=1$ |
| 通常的未来回报约定 | 1 | 0 | $1+0=1$ |

游戏已结束时，通常定义下没有剩余未来奖励，所以终局价值为 0。井字棋教学例子把结果直接存入终局表项，是另一种记分方式。**如果同时给胜利奖励 1，又令目标额外加上终局值 1，就会得到 2，重复计算胜利。**

### 5.8 自我对弈改变了学习目标

上面假定只我方学习、对手固定。双方同时学习时，昨天的对手与今天的对手不同，胜率随之改变，旧价值可能失准。

完美井字棋双方对弈会平局，但这一事实**不能证明任意自我对弈算法都会收敛**。用固定的参考对手评估，可以帮助区分自身进步与训练对手变化带来的影响。

## 6. 大状态空间、先验知识与历史脉络

来源：P48–50。

### 6.1 从价值表到函数近似

井字棋可以为各个局面建立表项；课件给出的双陆棋（Backgammon）状态规模约为 $10^{20}$，有限经验只能覆盖其中一小部分。Tesauro 的双陆棋工作把 TD 学习与神经网络结合，让经验能够跨局面泛化。

$$
V(s)\quad\text{由独立表项表示，改为}\quad\hat v(s,\mathbf w)\quad\text{由共享参数表示。}
$$

改变共享参数 $\mathbf w$，可能同时改变许多状态的价值预测。**补充解释：** 这既带来泛化，也意味着更新不再只影响一个格子，后续学习函数近似时要注意状态之间的相互影响。

### 6.2 可以利用先验与部分模型

井字棋学习者知道合法走法，能预测自己的落子后棋盘，能识别胜、负、平，但不必拥有对手策略的预测模型。RL 可以利用已有规则或模型，也能处理部分观测、大状态空间、内部还有更小决策过程的动作。完整棋盘观测和小表格是这个教学例子的便利条件，不是 RL 的普遍要求。

### 6.3 三条历史线索

| 线索 | 核心思想 | 课件例子 |
| --- | --- | --- |
| 试错学习 | 行为后果改变之后的动作选择 | Thorndike 的效果律、早期学习机器 |
| 最优控制 | 利用状态与价值优化跨时间决策 | Bellman 动态规划、Howard 策略迭代 |
| 时序差分学习 | 从连续预测之间的差异学习 | Samuel 跳棋、TD 预测、Actor–Critic 方法 |

课件指出，这些线索在 20 世纪 80 年代后期汇入现代强化学习。

## 7. 与 LLM、Bandit 和后续课程的联系

来源：P18、P51–52。

回看 LLM：策略是下一个 token 或工具动作的概率；奖励来自偏好、验证器或任务结果；价值与优势帮助分配信用和比较决策；采样回答决定训练能发现哪些解法。评估时还要看留出的任务表现，不能只看被优化的奖励是否变大。

多臂老虎机（Multi-armed bandit）去掉动作对未来决策状态的影响，专门研究**在未知奖励下怎样平衡探索和利用**。只能看到选中动作的奖励，持续选择当前估计最优的动作，会让低估的动作一直没有机会被纠正。

这里改用 Bandit 下标：动作 $A_t$ 后的奖励为 $R_t$。

$$
q_*(a)=\mathbb E[R_t\mid A_t=a],\qquad q_*=\max_a q_*(a).
$$

与始终选择最佳动作相比，$T$ 轮损失的期望奖励称为遗憾：

$$
\operatorname{Regret}(T)=Tq_*-\mathbb E\left[\sum_{t=1}^T R_t\right].
$$

第 2 周会比较样本均值、$\epsilon$-greedy 和 UCB，并学习直接优化动作概率的梯度 Bandit。课程随后进入 MDP 与 Bellman 方程，再发展价值方法、策略梯度、函数近似、规划、离线 RL 和语言模型应用。

<details>
<summary>参考答案</summary>

$$v_\pi(s)=0.2\times2+0.8\times4.5=4.$$

这里是对动作价值取策略加权平均，不是直接取最大值。取最大值会对应另一种动作选择规则。

</details>

**题 3。** $V(s)=0.6$、目标 $V(s')=0.2$、$\alpha=0.25$，一次井字棋备份后是多少？

<details>
<summary>参考答案</summary>

$$V_{\text{new}}(s)=0.6+0.25(0.2-0.6)=0.5.$$

误差为负，所以估计下降。更新结果应处于旧估计 0.6 与目标 0.2 之间。

</details>

**题 4。** 胜利时奖励设为 1，终局表项也设为 1，使用 $R+\gamma V$ 且 $\gamma=1$ 更新，哪里有问题？

<details>
<summary>参考答案</summary>

目标变成 2，重复记分。选择“奖励 1、终局未来价值 0”，或本例的“奖励 0、终局分数 1”。

</details>

**题 5。** “只要给策略网络训练，就属于 model-based RL”是否正确？“RL 必须每次在线与真实世界交互”是否正确？

<details>
<summary>参考答案</summary>

都不正确。这里的 model-based 指利用环境后果模型进行规划，而非泛指拥有神经网络。RL 也可以使用离线经验或模拟交互。

</details>

**题 6。** 只在贪心选择后备份与每次选择后都备份，为什么可能得到不同价值？

<details>
<summary>参考答案</summary>

它们希望描述的后续策略不同：前者面向贪心继续，后者面向实际带探索的继续。持续探索会改变未来胜率，价值必须说明对应哪一种行为。

</details>

**题 7。** 语言生成的前缀转移是确定的，是否说明策略不需要探索？

<details>
<summary>参考答案</summary>

不说明。策略仍要在很多候选 token 和回答之间选择。采样不同回答能发现不同解法，最终评分可以帮助提高成功行为的概率。

</details>
