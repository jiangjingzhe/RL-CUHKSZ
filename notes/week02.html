本章怎样学

核心问题：有多个奖励分布未知的动作，只能看到被选动作的奖励，怎样在尝试新动作与选择当前最优动作之间分配机会？

学习分为三段：第 1–4 节学习奖励估计与探索；第 5–6 节用 UCB 与遗憾衡量探索代价；第 7–8 节学习直接优化动作概率，以及让动作依赖上下文。

先备知识：期望、条件概率、样本均值、几何级数、指数与对数、简单偏导数。不熟悉的地方可以边读推导边补，不必先学完整套概率论。课件注明 UCB1 完整证明为选读且不考期末，所以它单独放在附录，但全文保留。该说明没有把整个 UCB 主题或 Softmax 推导排除在考试范围外。

1. 问题、真实价值与估计值

来源：P1–6。

1.1 k 臂老虎机

有 kkk 个可选动作，也称为臂（arm）。每一轮 ttt 选择 At∈{1,…,k}A_t\in\{1,\ldots,k\}At​∈{1,…,k}，得到奖励 RtR_tRt​。奖励分布事先未知，并且只观察被选动作的奖励，没选动作的奖励仍未知。

平稳 Bandit 中，各臂奖励分布不随时间改变。动作提供奖励与信息，但不控制未来决策状态的变化。

  • q∗q_*q∗​：所有动作里最大的真实平均奖励。
  • a∗a^*a∗：取得最大均值的一个最优动作，可以不唯一。

下标提醒：本章 AtA_tAt​ 对应 RtR_tRt​。 第 1 周一般序列决策的约定为 AtA_tAt​ 对应 Rt+1R_{t+1}Rt+1​。

补充解释：没有状态变化，为什么还关心长期？ 选择动作不会把环境带到另一个决策状态，但会改变我们掌握的信息。今天尝试一个未知动作，可能让明天开始选得更好，所以多轮奖励仍然存在探索与利用的权衡。

3. 增量更新与非平稳奖励

来源：P13–19。

3.1 不存全部历史，也能计算样本均值

现在只关注某一个动作。为匹配课件，RnR_nRn​ 表示这只臂第 nnn 次得到的奖励，QnQ_nQn​ 是观察这次奖励之前的估计，即已有 n−1n-1n−1 次观察。这里的 nnn 不等于全局决策轮数 ttt。

Qn+1=1n∑i=1nRi=1n[Rn+(n−1)Qn]=Qn+1n(Rn−Qn).\begin{aligned} Q_{n+1} &=\frac1n\sum_{i=1}^nR_i\\ &=\frac1n\big[R_n+(n-1)Q_n\big]\\ &=Q_n+\frac1n(R_n-Q_n). \end{aligned}Qn+1​​=n1​i=1∑n​Ri​=n1​[Rn​+(n−1)Qn​]=Qn​+n1​(Rn​−Qn​).​

只需存储每个动作的估计与计数。第一次观察时 n=1n=1n=1，于是 Q2=R1Q_2=R_1Q2​=R1​，初值完全被这次实际奖励覆盖。

补充解释。 原来的均值代表 n−1n-1n−1 个旧样本，所以旧样本总和是 (n−1)Qn(n-1)Q_n(n−1)Qn​。加入一个新样本后再除以 nnn，整理就得到增量公式。

3.2 一种贯穿课程的更新形式

新估计=旧估计+步长×(目标−旧估计).\text{新估计}=\text{旧估计}+\text{步长}\times(\text{目标}-\text{旧估计}).新估计=旧估计+步长×(目标−旧估计).
Qn+1=Qn+αn(Rn−Qn).Q_{n+1}=Q_n+\alpha_n(R_n-Q_n).Qn+1​=Qn​+αn​(Rn​−Qn​).

Bandit 的目标是这次奖励 RnR_nRn​；第 1 周井字棋的目标是后续局面的价值；后续 TD 方法会把奖励与后续价值放入同一个目标。相同的更新形式，并不意味着各算法的目标完全相同。

3.3 完整 epsilon-greedy 算法

对每个动作 a：Q(a) = 0，N(a) = 0
每一轮：
    以 1-epsilon 的概率从当前 Q 最大的动作中均匀选 A
    否则从所有动作中均匀选 A
    执行 A，观察 R
    N(A) = N(A) + 1
    Q(A) = Q(A) + [R - Q(A)] / N(A)
    其他动作的 Q 和 N 保持不变

顺序易错：先把新样本计入次数，再用新次数更新均值。 这里更新后的 N(A)N(A)N(A) 已包含本轮；前面定义的 Nt(a)N_t(a)Nt​(a) 是选本轮动作前的历史次数。

3.4 非平稳任务为什么要“忘记”一些过去

非平稳任务中，真实平均奖励可能随时间改变。样本均值对很久以前和最近的奖励给予同样权重，样本越来越多时，新证据影响越来越小，因此反应迟缓。

固定步长 α∈(0,1]\alpha\in(0,1]α∈(0,1]：

Qn+1=Qn+α(Rn−Qn)=(1−α)Qn+αRn.Q_{n+1}=Q_n+\alpha(R_n-Q_n)=(1-\alpha)Q_n+\alpha R_n.Qn+1​=Qn​+α(Rn​−Qn​)=(1−α)Qn​+αRn​.

它持续响应新证据。但如果某只臂后来一直不被选择，固定步长也无从发现它的变化，所以追踪变化需要更新规则，也需要持续采样。

4. 乐观初始化

来源：P20–22。

4.1 贪心也可以被初值驱动着探索

将初始价值设得比合理的奖励均值高。选中过的动作因现实奖励低于预期而下降，尚未尝试的动作仍保持高估，于是吸引后续选择。

原例（P21）： 仍是确定性奖励 q∗(A)=0.4q_*(A)=0.4q∗​(A)=0.4、q∗(B)=0.8q_*(B)=0.8q∗​(B)=0.8，但初值改成 (1,1)(1,1)(1,1)，使用样本均值。

  1. 第一次若选 A，观察后变为 (0.4,1)(0.4,1)(0.4,1)。
  2. 贪心会转而选 B，观察后变为 (0.4,0.8)(0.4,0.8)(0.4,0.8)。
  3. 之后贪心选择 B。

算法每次仍然选当前估计最大值，只是乐观初值使未探索动作暂时显得更好。

4.2 原实验与限制

图中两种方法都用固定步长 α=0.1\alpha=0.1α=0.1：蓝色为 Q1=5,ϵ=0Q_1=5,\epsilon=0Q1​=5,ϵ=0 的乐观贪心；灰色为 Q1=0,ϵ=0.1Q_1=0,\epsilon=0.1Q1​=0,ϵ=0.1。横轴步数，纵轴最优动作比例。

乐观初始化产生较强的早期探索，曲线早期波动明显，之后可达到较高最优动作比例。但初值的乐观影响逐渐消退，奖励后来变化时，它不会自动重新产生一次“初始探索”。因此不能把它当作持续探索的一般替代。

5. UCB：把不确定性纳入动作选择

来源：P23–25。

5.1 公式怎么读

UCB（Upper Confidence Bound，上置信界）选择：

At∈arg⁡max⁡a[Qt(a)+clog⁡tNt(a)],c>0.A_t\in\arg\max_a\left[Q_t(a)+c\sqrt{\frac{\log t}{N_t(a)}}\right],\qquad c>0.At​∈argamax​[Qt​(a)+cNt​(a)logt​​],c>0.

记整个选择分数为 Ut(a)U_t(a)Ut​(a)。Qt(a)Q_t(a)Qt​(a) 奖励过去表现好，附加项 clog⁡t/Nt(a)c\sqrt{\log t/N_t(a)}clogt/Nt​(a)​ 奖励尚不确定：

  • 次数少，附加项大，值得多了解。
  • 次数多，附加项小，估计相对充分。
  • 如果某个动作长时间被忽略，分母不变，而 log⁡t\log tlogt 增长，它会重新变得有吸引力。
  • 从未尝试的动作优先，可以等价地将其指数设为 +∞+\infty+∞，不能直接代入除以 0。

这里的 log⁡\loglog 为自然对数。附加项的有效性依赖奖励模型与系数选择，它不是一个不需要假设就自动正确的置信承诺。

6. 遗憾与 UCB1 保证

6.1 遗憾是在与谁比较

设最优真实均值为 q∗q_*q∗​，次优差距为：

Δa=q∗−q∗(a)≥0.\Delta_a=q_*-q_*(a)\ge0.Δa​=q∗​−q∗​(a)≥0.

RT=∑t=1TE[q∗−q∗(At)]=∑t=1T∑aΔaPr⁡(At=a)=∑aΔaE[∑t=1T1{At=a}]=∑aΔaE[Na(T)].\begin{aligned} \mathcal R_T &=\sum_{t=1}^T\mathbb E[q_*-q_*(A_t)]\\ &=\sum_{t=1}^T\sum_a\Delta_a\Pr(A_t=a)\\ &=\sum_a\Delta_a\mathbb E\left[\sum_{t=1}^T\mathbf1\{A_t=a\}\right]\\ &=\sum_a\Delta_a\mathbb E[N_a(T)]. \end{aligned}RT​​=t=1∑T​E[q∗​−q∗​(At​)]=t=1∑T​a∑​Δa​Pr(At​=a)=a∑​Δa​E[t=1∑T​1{At​=a}]=a∑​Δa​E[Na​(T)].​

6.5 证明直觉与解读

置信界通常不失效时，最优臂的上界仍高于它的真实均值。次优臂被试得越多，它的附加项越小。当它的不确定性足够小，相比最优臂的差距就无法被遮住。此后继续选择它，只能发生在置信界失效的少数轮次。

因此次数上界由两部分组成：约 log⁡T/Δa2\log T/\Delta_a^2logT/Δa2​ 级别的必要采样代价，加上置信界偶尔失效造成的有界代价。

应如何读结论 不能推出什么
小差距需要更多样本分辨，差距相关上界较大 每一个具体小差距任务实际遗憾都必然更大
固定差距时遗憾至多按对数级增长 任意奖励模型、任意 UCB 系数都自动有同一界
平均每轮损失趋于零 有限轮数就保证每次都选最优
定理针对上述平稳有界奖励模型 直接适用于非平稳任务或无界高斯奖励

补充解释：差距小的两面性。 两个动作很接近，区分它们更难，但每次选错损失也小。次数界里的 1/Δa21/\Delta_a^21/Δa2​ 乘以每次损失 Δa\Delta_aΔa​，得到遗憾界中的 1/Δa1/\Delta_a1/Δa​。这是上界的依赖关系，不是对所有实例实际损失的单调性结论。

Q(x,At)←Q(x,At)+αt[Rt−Q(x,At)].Q(x,A_t)\leftarrow Q(x,A_t)+\alpha_t[R_t-Q(x,A_t)].Q(x,At​)←Q(x,At​)+αt​[Rt​−Q(x,At​)].

原例（P43）： 蓝色下选择 A，得到奖励 1，原估计为 0.60，αt=0.20\alpha_t=0.20αt​=0.20。

Q(Blue,A)←0.60+0.20(1−0.60)=0.68.Q(\text{Blue},A)\leftarrow0.60+0.20(1-0.60)=0.68.Q(Blue,A)←0.60+0.20(1−0.60)=0.68.

其他所有表项保持不变。探索需要在每个上下文内进行，不能用“蓝色下 A 的很多样本”直接替代“红色下 A 的证据”。

9. 方法比较与 MDP 预告

来源：P44–46。

9.1 分开考虑“怎样估计”与“怎样选择”

方法 选择机制 需要留意
ϵ\epsilonϵ-greedy 偶尔从全部动作均匀随机选 固定探索有长期代价
乐观初值 给初始估计高分，贪心选择也会尝试新动作 探索动力是暂时的
UCB 价值估计加不确定性附加项 需要匹配奖励模型的置信界与系数
梯度 Bandit 用学到的偏好经 Softmax 选动作 步长、基线影响学习；偏好不是价值估计

估计规则和选择规则是两项设计：例如 ϵ\epsilonϵ-greedy 既可以结合样本均值，也可以结合固定步长估计。调整 ϵ\epsilonϵ 改变探索，调整 α\alphaα 改变对新奖励的响应，二者作用不同。

9.2 五条主线

本章依次建立：用观察结果估计动作价值；用增量更新处理固定或变化的均值；通过探索收集证据并用遗憾核算代价；用奖励相对基线的差直接优化动作概率；根据上下文选择合适动作。

9.3 从 Bandit 到 MDP

问题 动作的后果
普通 Bandit 从选中臂的分布获得奖励
上下文 Bandit 获得依赖当前上下文和动作的奖励
MDP 获得奖励，并改变下一状态，影响未来决策机会

MDP 中，单步平均奖励不足以评价动作，还必须考虑它将系统带到哪里、以后会发生什么。下一周的主题是马尔可夫性质、回报、价值函数与 Bellman 方程。

题 1。 k=4,ϵ=0.2k=4,\epsilon=0.2k=4,ϵ=0.2，唯一贪心动作与每个非贪心动作概率是多少？若有两个并列贪心动作呢？

参考答案

唯一贪心：0.8+0.2/4=0.850.8+0.2/4=0.850.8+0.2/4=0.85，其余各 0.05。两个并列贪心：各 0.8/2+0.2/4=0.450.8/2+0.2/4=0.450.8/2+0.2/4=0.45，其余各 0.05。两种情况下总和都为 1。

题 2。 某只臂前四次奖励均值为 0.6，第五次奖励为 1。样本均值怎样更新？若改成固定步长 0.2，从相同旧值出发呢？

参考答案
Qnew=0.6+15(1−0.6)=0.68.Q_{\text{new}}=0.6+\frac15(1-0.6)=0.68.Qnew​=0.6+51​(1−0.6)=0.68.

固定步长 0.2 恰好也得到 0.68。它们只在这次步长恰好相等，不能据此认为两个方法总是相同。

题 3。 α=0.5\alpha=0.5α=0.5，从 Q1=0Q_1=0Q1​=0 开始，连续观察奖励 R1=2,R2=0R_1=2,R_2=0R1​=2,R2​=0。最终估计和三个权重是多少？

参考答案

Q2=1Q_2=1Q2​=1，Q3=0.5Q_3=0.5Q3​=0.5。展开为 Q3=0.25Q1+0.25R1+0.5R2Q_3=0.25Q_1+0.25R_1+0.5R_2Q3​=0.25Q1​+0.25R1​+0.5R2​，权重总和为 1。

题 4。 两臂均值 0.4、0.8，固定 ϵ=0.1\epsilon=0.1ϵ=0.1，1000 轮仅随机探索分支就至少贡献多少期望遗憾？

参考答案

次优差距为 0.4，随机分支选次优臂概率为 0.05，所以下界为 1000×0.05×0.4=201000\times0.05\times0.4=201000×0.05×0.4=20。贪心分支若也选错，还会产生额外遗憾。

题 5。 UCB 指数算成 1.179，而奖励范围是 [0,1][0,1][0,1]，是否说明计算必错？10 臂高斯实验可以直接套本章 UCB1 有界奖励定理吗？

参考答案

指数超过 1 不一定错，它是用于选择的上界评分，不是实际奖励。高斯奖励无界，不能直接套 [0,1][0,1][0,1] 的定理，需要合适的集中不等式与系数。

题 6。 H=(0,0)H=(0,0)H=(0,0)，α=0.1,b=4\alpha=0.1,b=4α=0.1,b=4，选动作 1，奖励 3。新的偏好和动作 1 概率是多少？

相对奖励为 −1，所以偏好变化为 (−0.05,+0.05)(−0.05,+0.05)(−0.05,+0.05)。

πnew(1)=e−0.05e−0.05+e0.05≈0.475.\pi_{\text{new}}(1)=\frac{e^{-0.05}}{e^{-0.05}+e^{0.05}}\approx0.475.πnew​(1)=e−0.05+e0.05e−0.05​≈0.475.

奖励虽然是正的，但低于基线，选中动作概率下降。

题 7。 为什么不能说“未选动作没观察到奖励，所以梯度 Bandit 不应更新其偏好”？

参考答案

偏好控制归一化概率，不是各动作奖励均值。Softmax 对数梯度对未选动作也有 −πt(a)-\pi_t(a)−πt​(a) 项，所以一次采样就会对所有偏好产生相应梯度分量。

题 8。 蓝色下 B 收到奖励 0，旧 Q(Blue,B)=0.3Q(\text{Blue},B)=0.3Q(Blue,B)=0.3、步长 0.2，怎样更新？红色下 B 的表项会变吗？

Q(Blue,B)=0.3+0.2(0−0.3)=0.24Q(\text{Blue},B)=0.3+0.2(0-0.3)=0.24Q(Blue,B)=0.3+0.2(0−0.3)=0.24。其他表项包括红色下 B 都不变。

题 9。 “随着 TTT 增大，UCB1 总遗憾趋于 0”是否是本章结论？

参考答案

不是。定理给出固定差距下总遗憾的对数级上界，趋近 0 的是平均遗憾 RT/T\mathcal R_T/TRT​/T。
